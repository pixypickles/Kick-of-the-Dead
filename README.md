# Kick of the Dead v0.2

GitHub Pages向けのHTML5アクションゲーム試作版です。

## GitHubへのアップロード

このZIPを展開し、**中に入っているファイルをすべてリポジトリ直下へアップロード**してください。

重要：`index.html`、`main.js`、`style.css` と各PNG画像が、同じ階層に置かれる構成です。

```text
/
├── index.html
├── main.js
├── style.css
├── neutral.png
├── mid_kick_start.png
├── mid_kick_hit.png
├── low_kick_start.png
├── low_kick_hit.png
├── high_kick_start.png
├── high_kick_hit.png
├── jump.png
├── jump_attack_start.png
├── jump_attack_hit.png
├── landing.png
├── special_pickup.png
└── special_fire.png
```

以前のファイルを残したままでも構いませんが、同名ファイルは上書きしてください。

## 操作

- 左／右：向き変更
- KICK：中段蹴り
- 上＋KICK：上段蹴り
- 下＋KICK：下段蹴り
- JUMP：通常ジャンプ
- 上＋JUMP：高ジャンプ
- 空中KICK：ジャンプ回転蹴り
- SPECIAL：ゲージ100%時にマシンガン

## v0.2の変更

- リポジトリ直下のPNG画像を直接読み込むよう統一
- 画像読み込み失敗時もゲームを継続
- スマホ用タッチ操作
- 敵4種、高さ1〜5
- HP、スコア、必殺ゲージ
- マシンガン必殺技


## v0.3 の変更

- キャラクター画像の外周につながった白背景だけを透過
- 白い道着は輪郭内にあるため、できるだけ残す処理を採用
- 地上蹴りの攻撃範囲を拡大
- 地上蹴りで密集した敵を最大2体まで倒せるよう変更
- ジャンプ攻撃で最大4体まで巻き込めるよう変更
- 敵との接触判定を少し小さく調整
- 被弾後の無敵時間を延長
- 同じ側に敵が詰まりすぎないよう出現間隔を調整


## v0.4 の変更

- 起動時に EASY / NORMAL / HARD の難易度選択画面を追加
- 難易度選択中に画像をバックグラウンド読み込み
- 13枚すべての読み込み完了を待たずにゲーム開始可能
- 未読込モーションは一時的に代替表示
- EASY：HP8、敵速度低下、出現間隔長め、必殺ゲージ増加量アップ
- NORMAL：標準
- HARD：HP3、敵速度上昇、出現間隔短め、必殺ゲージ増加量ダウン


## v0.5 の変更

- 全キャラクター画像を 1536px PNG から 640px WebP に軽量化
- ゲーム上の表示サイズに対して十分な画質を維持
- ニュートラル画像を最優先で読み込み
- 残りの画像は2枚ずつバックグラウンド読み込み
- 新しい砂煙なしのマシンガン画像を採用
- PNGファイルは不要になり、同名のWebPファイルを使用

GitHubでは、古いPNG画像を削除してから、このZIPのWebP画像とコードをアップロードしてください。


## v0.6 の変更

- 下段・中段・上段・ジャンプ攻撃の当たり判定を、実際の画面上の高さで判定
- 敵を対応する攻撃レーンの高さに描画
- 上段用スケルトンや飛行悪魔は、対応する高さまで浮くよう調整
- 横方向だけでなく縦方向の距離も当たり判定に使用
- 細長いスマホでも難易度選択画面を全画面スクロール可能に変更
- 画面下に隠れていた NORMAL / HARD を表示可能に修正


## v0.7 の変更

- スケルトンを削除
- 高さ1：足元を走るゾンビ犬
- 高さ2：中段位置に浮遊する頭蓋骨
- 高さ3：上段位置を飛ぶゾンビカラス
- 高さ4・5：飛行悪魔を継続
- 敵の絵を当たり判定部分だけのコンパクトな形に変更

- 必殺技で倒した敵からは必殺ゲージが増えないよう修正
- EASYでも必殺技を連続発動し続けにくい仕様へ変更


## v0.8 の変更

- 攻撃高さを実際の画像に合わせて4段階へ再調整
- 下段：高さ1

- 上段：高さ3（旧高さ4相当の位置）

- 敵の中心と攻撃レーンの中心が一致するよう再配置
- 必殺技中の撃破では必殺ゲージが増えない仕様を維持


## v0.9 の変更

- 黄色い頭蓋骨を追加
  - 下段と中段の間をバウンドしながら接近
  - EASYでは出現率を大幅に低下
- 赤い頭蓋骨を追加
  - 下段・中段・上段をバウンドしながら接近

## v1.0 の変更

- ジャンプ攻撃の高さ判定を固定最上段から動的判定へ変更
- 空中で足の高さが合えば、下段・中段・上段・最上段すべてに命中
- 方向ボタンを大幅に半透明化し、敵が隠れにくい表示へ変更
- 左下と右下に斜め下ボタン（↙／↘）を追加
- ↙／↘を押したままKICKで、その方向へ即座に下段攻撃
- 左右および斜め下ボタンの長押しで、中央付近を少し前後移動
- 移動後も敵の現在位置を基準に攻撃方向を判定
- PCでは Q＝左下、E＝右下
